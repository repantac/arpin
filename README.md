# ARPIN - Arqueologia y Proyectos Integrales S.A.S

Sitio web corporativo para ARPIN, empresa colombiana especializada en arqueologia,
investigacion del patrimonio cultural y proyectos de desarrollo integral.

Desarrollado como proyecto de portafolio para el programa de Tecnologia en Desarrollo de Software (UNAD).

> El contenido de texto es parcialmente de ejemplo y no representa en su totalidad informacion real de la empresa.

---

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Font Awesome (iconos)
- Google Fonts (tipografia Lato)

---

## Funcionalidades

- Navegacion multipagina con menu responsive para movil
- Menu hamburguesa con apertura y cierre animado
- Paginas: Inicio, Nosotros, Servicios, Proyectos, Blog y Contacto
- Formulario de contacto
- Mapa de ubicacion embebido
- Galeria de imagenes con efecto hover
- Diseno responsivo para dispositivos moviles y escritorio
